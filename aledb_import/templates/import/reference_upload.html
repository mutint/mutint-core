Give an experiment its reference genome. Do this first when you plan to import bare .gd files — a .gd carries no reference of its own, and every sample in an experiment must share one.

You can upload any of:

  • GenBank (.gbk, .gb, .gbff) — sequence and annotation
  • GFF3 (.gff, .gff3) — must include its ##FASTA section
  • FASTA (.fa, .fasta, .fna) — sequence only, no genes

Whatever you upload is normalized to one canonical pair — a GFF3 of genes only, plus a FASTA — so the same genome always compares equal regardless of the format it arrived in. Importing a breseq folder into this experiment later will check its reference against this one.
