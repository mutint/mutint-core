Drop breseq result folders below to load their mutations and store the alignments. From each sample folder only these are uploaded — everything else a breseq run writes stays on your machine:

  • output/annotated.gd — the mutations
  • data/reference.gff3, data/reference.fasta — the reference, which every sample in an experiment must share
  • data/reference.bam, data/reference.bam.bai — the alignment

Each sample's A-F-I-R identity is taken from its folder name (e.g. 3-30000-1-1); names that are not A-F-I-R each get their own isolate.

Bare .gd files cannot be imported here: every sample in an experiment must share a reference genome, and a .gd on its own carries none.
