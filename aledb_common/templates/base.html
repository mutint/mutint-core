{% comment %} Bootstrap arrives inside the DataTables bundle below, not on its own. A DataTables combined build bundles its styling framework, so the bs-3.3.7 variant carries Bootstrap's own JS. Loading bootstrap.min.js as well meant two copies, and Bootstrap's data-api binds delegated handlers on document -- so every [data-toggle] fired twice and a modal opened and closed within the same millisecond. Dropping the bs- component is not an option: that build 404s on the CDN. Order matters here. bootstrap-toggle extends Bootstrap and must come after it, which is why it now follows the bundle rather than preceding it. {% endcomment %}
