Downloads are generated from the stored reference, which keeps the sequence and the genes breseq annotates against; the file it was imported from is not kept. A GenBank download therefore carries CDS, RNA and repeat features with their names, locus tags and products, and no translations or source record.

A sequence's role is which breseq reference option it is passed under when a run is launched from this MutInt. Reference (-r) fits coverage to it on its own. Contig (-c) fits one coverage distribution across every sequence marked that way, which is what the contigs of a single draft assembly want — and what stops a short contig being fitted alone. Junction-only (-s) uses it only for calling junctions against the others, with no coverage fitted and no mutations called on it; a transposon that is not in the reference genome is the usual case. A role marked suggested was read from the sequence's name and nobody has confirmed it. Changing one alters no sequence and no annotation.

An accession is never guessed from a sequence name — a contig called NC_000913 is usually one and a contig called REL606 is not, and a wrong guess would draw a convincing picture of the wrong gene. What you enter is only a proposal: it is accepted only if NCBI's record for it is byte-for-byte this sequence. Confirming one lets every mutation on it be opened in NCBI's annotation from the Reference column of any mutation table.
