This site runs aledb-core {{ aledb_version }}, a platform for storing and exploring mutations from adaptive laboratory evolution (ALE) experiments. It imports resequencing output, annotates mutations against an experiment's reference, and presents them as searchable, filterable, exportable tables across experiments and samples.

Mutation data generation

Mutation calls are imported from the breseq resequencing pipeline, and re-annotated internally against the reference stored for each experiment.

Deatherage, D.E., Barrick, J.E. (2014) Identification of mutations in laboratory-evolved microbes from next-generation sequencing data using BreSeq. Methods Mol. Biol.
